This lab builds the **substrate** — not the product — that lets a Claude Opus 4.8
agent (Bedrock, `global.anthropic.claude-opus-4-8`) read code semantically, run
experiments in a closed sandbox, and verify hypotheses in a loop. The substrate must be
*trustworthy first* so the fuzzy audit content can be iterated safely on top of it.

Two invariants govern everything:

- **E3** — every target-code experiment runs inside a throwaway sandbox launched with
  `--network=none` by default.
- **E12** — every tool call, sandbox lifecycle event, and gate decision appends to a
  hash-chained WORM audit log (S3 Object Lock or `chattr +a`).
