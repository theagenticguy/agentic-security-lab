This repo implements the runtime, sandbox, findings ledger, and audit-log layers a
code-analysis agent depends on. The v1 agent is Claude Opus 4.8 on Amazon Bedrock
(`global.anthropic.claude-opus-4-8`); the layers are written so a different agent
runtime can replace it without changes elsewhere
(see [ADR-002](/agentic-security-lab/adrs/0002-agent-runtime-protocol/)).

The contract these layers enforce is a list of 19
[Easy Approach to Requirements Syntax (EARS) invariants](/agentic-security-lab/concepts/ears-invariants/).
Two govern v1 day-to-day:

- [**E3**](/agentic-security-lab/concepts/ears-invariants/#e3) — every target-code
  experiment runs inside a throwaway sandbox launched with `--network=none` by
  default.
- [**E12**](/agentic-security-lab/concepts/ears-invariants/#e12) — every tool call,
  sandbox lifecycle event, and gate decision appends to a hash-chained
  Write-Once-Read-Many (WORM) audit log (Amazon S3 Object Lock or `chattr +a`).
