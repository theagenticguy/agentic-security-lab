## Acronyms

| Term | Expansion | Notes |
|---|---|---|
| ADR | Architecture Decision Record | The MADR (Markdown Architecture Decision Record) flavor. Source-of-truth lives in `/adr`; the docs site mirrors it read-only. |
| AGS | AWS Global Services | Internal organization name. Not load-bearing for the substrate. |
| AMI | Amazon Machine Image | Used by the EC2 Image Builder pipeline (ADR-009) to bake the gVisor host image. |
| API | Application Programming Interface | |
| ASan | AddressSanitizer | Memory-error detector compiled in via `clang -fsanitize=address`. |
| BM25 | Best Matching 25 | Probabilistic lexical-ranking function (Robertson & Zaragoza, 2009). The `bm25s` package is a pure-Python implementation. |
| CDK | AWS Cloud Development Kit | Infrastructure-as-code framework. The repo's CDK stacks live under `infra/cdk`. |
| CI | Continuous Integration | GitHub Actions in this repo. |
| CLI | Command-Line Interface | |
| CMK | Customer Managed Key | An AWS Key Management Service (KMS) key the customer controls — required for the encrypted gp3 root volume in ADR-009. |
| DAST | Dynamic Application Security Testing | OWASP ZAP is the DAST tool baked into the sandbox image. |
| DFD | Data-Flow Diagram | The threat-model artifact records boundaries, assets, and flows in DFD form. |
| DSN | Data Source Name | The Postgres connection-string format used by `PostgresLedger`. |
| DDB | Amazon DynamoDB | Single-table design, deferred behind `LedgerPort` (ADR-004, ADR-010). |
| EARS | Easy Approach to Requirements Syntax | Mavin et al., 2009. See [EARS invariants](/agentic-security-lab/concepts/ears-invariants/). |
| EBS | Amazon Elastic Block Store | gp3 root volume; io2 Block Express for durable audit (ADR-009). |
| EC2 | Amazon Elastic Compute Cloud | The substrate runs on `c7g.metal` Graviton bare metal (ADR-009). |
| GHAS | GitHub Advanced Security | Required to run CodeQL on private repos; auto-enabled on public. |
| GSI | Global Secondary Index | DynamoDB index used to serve open-hypothesis and suppression-by-rule reads (ADR-004). |
| gVisor | (not an acronym) | Google's userspace-kernel container runtime; the `runsc` binary intercepts guest syscalls. The v1 default (ADR-003, ADR-009). |
| GFM | GitHub Flavored Markdown | Markdown dialect used in the docs (`remark-gfm`). |
| HTTP / HTTPS | Hypertext Transfer Protocol (Secure) | |
| IAM | AWS Identity and Access Management | |
| IDE | Integrated Development Environment | |
| JCS | JSON Canonicalization Scheme | RFC 8785; canonicalizes JSON for deterministic hashing in the WORM chain. |
| JSON | JavaScript Object Notation | |
| JSONL | JSON Lines | One JSON object per line; the WORM audit log format (ADR-005). |
| JSONB | JSON Binary | PostgreSQL's binary JSON column type; the SARIF property bag is JSONB-shaped (ADR-010). |
| KMS | AWS Key Management Service | |
| KVM | Kernel-based Virtual Machine | A gVisor platform that requires hardware virtualization (`/dev/kvm`); only available on EC2 `.metal` instances (ADR-009). |
| LXD | Linux Container Daemon | Canonical's system-container manager; underpins Workshop. |
| MADR | Markdown Any Decision Records | The Markdown flavor of ADRs the repo uses. |
| OASIS | Organization for the Advancement of Structured Information Standards | The standards body that publishes SARIF. |
| OWASP | Open Worldwide Application Security Project | |
| PoC | Proof of Concept | An exploit demonstrator — referenced by URI from a SARIF result, never inlined. |
| PR | Pull Request | |
| RDS | Amazon Relational Database Service | The cloud-Postgres path for `PostgresLedger` runs on RDS or Aurora Serverless v2. |
| RFC | Request for Comments | IETF specification series. |
| SARIF | Static Analysis Results Interchange Format | OASIS v2.1.0 (ADR-006); the on-the-wire format for findings. |
| SAST | Static Application Security Testing | semgrep, CodeQL, bandit are the SAST tools in the stack. |
| SBOM | Software Bill of Materials | Generated by syft; scanned by grype/trivy. |
| SDK | Software Development Kit | |
| seccomp | Secure Computing | Linux syscall-filter framework. |
| SQL | Structured Query Language | |
| SSH | Secure Shell | |
| STRIDE | Spoofing, Tampering, Repudiation, Information disclosure, Denial of service, Elevation of privilege | The threat-categorization taxonomy used for the threat model. |
| systrap | (not an acronym) | A gVisor platform that intercepts syscalls via `seccomp SECCOMP_RET_TRAP`; the v1 default (ADR-009). |
| tmpfs | Temporary File System | RAM-backed Linux filesystem; used for sandbox scratch. |
| UID | User Identifier | |
| URI | Uniform Resource Identifier | |
| WAL | Write-Ahead Log | SQLite's concurrent-writer journal mode. |
| WORM | Write-Once-Read-Many | The audit-log property: append-only with at-rest enforcement (`chattr +a` or S3 Object Lock). See ADR-005. |

## Project-specific terms

| Term | Definition |
|---|---|
| Agent runtime | The component that drives a language model through a tool-use loop. The repo uses the Claude Agent SDK (ADR-001) behind the `AgentRuntime` Protocol (ADR-002). |
| Audit log | The hash-chained JSONL stream defined in ADR-005. Sometimes called the WORM log. |
| Confidence score | A scalar in [0, 1] combining pattern, recall, and reachability axes. See `asec-confidence` and ADR-008. |
| Findings ledger | The durable store for `Finding` records. Lives behind `LedgerPort`. SQLite locally, Postgres in cloud (ADR-010). |
| Hook | A user-supplied function the agent runtime calls at lifecycle points (e.g. PreToolUse). |
| Hypothesis board | An append-only list of conjectures the agent records during a run. |
| `permission_gate` | The PreToolUse hook implementation that enforces deny-by-default tool gating (ADR-007). |
| Skill | A `SKILL.md` file declaring `name`, `description`, and `allowed-tools`. The deny-by-default gate enforces the `allowed-tools` list (ADR-007). |
| Subagent | A child agent process the orchestrator dispatches; results are merged back. |
