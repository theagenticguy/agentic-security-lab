# Security Policy

## Reporting a vulnerability

This is an internal AWS lab project. **Do not** open public issues for security
vulnerabilities.

Report suspected vulnerabilities through the internal AWS security disclosure process.
Contact the AGS Tech AI Engineering NAMER team or follow your internal security
incident-reporting runbook. Provide a description, reproduction steps, and impact
assessment.

## Scope

This repository is alpha-stage substrate scaffolding and is **not** production-grade.
The `apps/pr-reviewer` app is a wiring demonstration only. Do not deploy it against
untrusted code outside the sandbox isolation guarantees described in the README (E3, E12).
